# Canvas 交互契约

- 原生工作流标签页承载项目和卡片编辑；不另开窗口、iframe 或第二套图编辑器。
- 新建、打开、编辑命令保留当前工作流。编辑上下文属于各标签页 extra，不使用全局 editing。
- 项目创建必须显式选择空目录；读取不创建项目。核心文件不合法就报错，不静默恢复为空图。
- 目录浏览限于所属实例 output。项目、模板及素材路径都由后端检查。
- 节点使用默认标题、插槽、按钮、文本框和 combo；不自绘卡片皮肤或缩放系统。
  端点名称右键直接显示改名、移动和删除；不保留拖拽排序、手柄或动画。
  经典节点与 Nodes 2.0 共用操作逻辑，名称不能为空或纯空白。
- 按画布标记启用菜单和队列限制，不改变普通工作流的行为。经典 LiteGraph 必须可用。
- 卡片模板和实例分离，稳定 ID 不依赖显示名称和顺序。
  原生 clone/复制粘贴通过卡片自身生命周期创建新实例，不修改全局剪贴板或 LiteGraph 原型。
  参数、工作流副本和素材选择独立；已有媒体只读共用。多卡片粘贴保留内部连线。
  分配期间隔离副本控件，提前排队的保存不提交占位卡片；失败仅移除失败副本。
  同一项目内复制受支持，跨项目粘贴明确拒绝，不读取其它项目来偷偷补齐资产。
- 素材文本内联保存；视频使用 VIDEO。中间结果不能直接成为跨卡片输出。
- 每个素材桩必须绑定 Inputs 的 position；Outputs 仅声明可选的跨卡片输出。
  未导出的桩及其上游计算不能在复制到项目时被删除；卡片按 position 展示其预览与操作。
- 输入输出端点数据口仅支持 IMAGE/VIDEO/AUDIO/STRING，位置标记不传递素材。
- Inputs 的 parameter 端口支持 INT/FLOAT/BOOLEAN/STRING/COMBO；在卡片上显示原生表单，
  在工作流也只有右侧输出口，左侧保持空白，不创建多余连线口。
  默认值、控件设置和实例参数值均属于私有 workflow.json，按稳定 ID 保存。
  Outputs 不接受 parameter 端口；模型、latent 等运行时对象不能作为参数持久化。
- DynamicCombo 复用原生分支控件，只导出可填写参数组，支持嵌套分支。
  各分支值属于私有 workflow.json，切换不丢值、不自动执行；编译时仅展开选中分支。
  整组与组内字段不能分别接线，避免覆盖。工作流执行和卡片执行使用相同的分支语义。
- 文本桩只有 text 入口，连接后仍显示文本框。媒体选择复用标准 combo/上传控件。
- Nodes 2.0 的媒体历史复用原生预览选择面板，经典界面仍为标准 combo。
  项目卡片与编辑页只提供所属项目的候选文件和缩略图，不混入全局生成历史。
  图片/视频列表使用静态缩略图；音频不预加载播放器。预览 URL 不作为持久化标识。
  IMAGE 素材保存/重读保留 alpha；普通工作流加载时重新合并原生 LoadImage 分离的 alpha。
  JPEG 海报对白底合成透明部分，不改变推理原图；渲染规则变更须更新海报缓存版本。
  下拉中的原生上传在项目视图关闭，预览右键或拖入统一使用项目导入，不写入全局 input。
  动态卡片的媒体定义由 material_combo.js 的单一适配边界注册，按生命周期释放引用、批量刷新。
  Frontend 1.53.6 尚无单控件媒体定义接口，适配通过 app.updateVueAppNodeDefs 更新渲染元数据；
  不注册新节点、不重建图或控件，历史刷新/选择不重复更新定义。接口缺失时保留普通下拉。
  同一帧的注册/释放合并为一次定义刷新；不通过私有 store 绕过官方边界。
  前端升级需要重跑 material_picker.mjs，再决定移除该定义适配；不导入私有 store 或打包组件。
- 稳定 ID 只用于控件和持久化键；用户可见标签及文本占位提示使用条目名称。
- 媒体桩用普通开关控制卡片上传；同时限制上传按钮与拖入，不限制历史选择。
  开关属于工作流 properties，不增加无作用的后端执行参数；关闭时同时禁用预览右键和拖入。
- Inputs 参数的 canvas_hidden 仅定义展示；position 可隐藏所绑定的桩，数据连线不变。
  工作流中的输出标签和参数控件显示“· 隐藏”；实际名称、端口 ID 和连线不变。
  隐藏窗口与普通表单共用参数保存边界，DynamicCombo 的分支及控制模式仍写入私有工作流。
  不重建插槽、不改变稳定 ID；卡片隐藏参数和素材文字停止输入 300 ms 后自动保存。
  局部运行、关闭和 Esc 先等待最新输入持久化，失败保留窗口并阻止执行旧参数。
  失败时显式放弃只清除该窗口未保存修改的错误，不清除其它控件的失败状态。
  项目根节点也使用“隐藏参数”入口，Chat API 配置在窗口的 Chat 分组中，仍使用应用/取消。
  窗口复用原生表单语义和主题变量，下拉、布尔开关和按钮使用统一样式。
- 原生 Save / Ctrl+S / 关闭时保存都按当前标签页所属文件执行：模板库 JSON、
  项目 cards/<id>/workflow.json 或 canvas.json。普通工作流不改变目标。
  只适配托管标签页的文件操作，不修改核心、类原型或普通工作流保存方式。
  失败/取消不清除 dirty 状态；卡片保存期间的新编辑保留并阻止关闭丢失。
  卡片另存为独立模板；画布不允许只复制展示图的另存为。
  托管标签页的菜单“保存卡片”与 Ctrl+S 使用同一保存目标；普通工作流通过该菜单创建模板。
  模板侧边栏支持重命名/复制，原生标签支持 Rename/Duplicate；复制和另存为生成独立身份。
  重命名与自动保存串行执行，按文件版本检查冲突，更新标签引用，不允许覆盖已有目标。
  未完成模板可另存为草稿；原文件冲突不妨碍另存为独立文件，不覆盖冲突版本。
  实例编辑页 Ctrl+S 先保存自己的工作流，再保存所属画布。普通文件仍按原生语义保存。
  导出清除项目媒体绑定、状态和直接填写的明文 Key；项目全局凭据从不注入卡片文件。
- 托管标签使用 workflows/canvas/ 下的逻辑键，文件仍写入项目/模板库，不创建 userdata 副本。
  画布标题包含项目目录名；会话仅记录文件引用，标签顺序、当前标签和草稿复用官方持久化。
  恢复时先注册文件描述，切到对应标签才读取项目；原生列表同步不得移除托管描述。
  遵从 Comfy.Workflow.Persist；关闭标签后移除会话引用，不能刷新后重新打开。
  列表加载/同步只监听公开的 Pinia $onAction，不替换 loadWorkflows/syncWorkflows 实现。
  插件会话清单按 API 根地址和用户隔离，只记录逻辑路径及文件引用，镜像到 localStorage
  支持浏览器会话重启；普通保存不重命名逻辑键，避免丢失原生指针/草稿。
  旧 canvas/ 命名空间通过 document_session.js 的一次性适配桥迁移，仅处理明确打开/选中的
  旧路径和对应草稿。不删除旧草稿，不通过名称接管真实 workflows/canvas/ 原生文件。
  不支持或损坏的清单保留原文并报错，普通标签继续原生恢复。
- 项目实例删除输入端点外的测试来源、输出端点外的测试消费者；全局模板不删除。
  原生嵌套子图保留必要计算及边界连线。项目卡片编辑页禁止整图 Run，仅允许执行到素材桩。
- 卡片文件持久化完整的原生编辑器快照，不使用 graphToPrompt 压缩后的 workflow。
  Autogrow 分组规范化只处理文件描述，同步根图/子图连线槽号；不增删槽位、不修改运行时对象。
  执行 prompt 仍由原生接口派生，两种快照不能混用；新建、另存和实例保存复用同一入口。
  原生克隆/子图配置还会重排动态槽位，web/lib/native_graph.js 按名称恢复原生 Autogrow、
  DynamicCombo 及 JS 增加的槽位；官方与第三方节点使用同一机制，不仅限于本插件。
  没有槽位变化的普通节点走原生路径；不补写推理参数，不修改核心或全局 LiteGraph 类原型。
  Frontend 1.53.6 转换已有子图时会过早清理嵌套定义；仅在该转换的移除/接入交接期间，
  按子图依赖顺序恢复仍需使用的定义。普通删除不恢复，不能留下废弃模型/节点引用。
  前端升级后须去掉适配重跑动态槽位回归，通过后删除该临时修复。
  正常恢复按原生连线 ID/端口索引查找，不逐节点扫描全图；只有额外克隆槽位使用单次扫描。
  端点排序与原生恢复共用 input_slots.js 的连线迁移原语，不复制移位算法。
  打开/保存卡片前检查端口镜像、实际连线两端和类型；不一致必须报错，不能静默派生执行图。
  已经被保存为自洽的同类型错接无法反推原意，需要用户重新确认连线。
- 项目编辑页与外层卡片共用项目历史和导入接口，选择立即持久化并同步两种视图。
  新桩先保存再选择；结构/参数仍显式保存。全局模板使用实例普通素材目录。
  导入与选择共用按项目排序的写入队列；保存/局部执行先等待所有已发起的素材修改。
  保存失败阻止执行旧素材；该桩重新选择成功后解除失败状态，不吞掉错误继续推理。
  素材、卡片参数和项目设置共用 SerialWrites 的失败/重试契约，但分别拥有各自的队列。
  参数/设置写入失败也阻止保存与执行；只有同一项重试成功才能解除，不能由无关修改清除。
  显式“撤销未保存修改”可丢弃失败的界面编辑并重载文件，不影响已发布素材或服务端任务。
  编译前再次检查参数写入错误；不把模型执行失败记录为参数保存失败。
  卡片表单与素材区域按 Inputs 的交错布局展示，不能把所有表单单独移到素材之前。
- 不启用媒体 combo 对所有 execution_success 的全局刷新；相关导入/生成后才刷新列表。
  保留旧远程 combo 辅助控件的序列化位置，隐藏且固定关闭，避免旧工作流字段移位。
- canvas.json 只拥有拓扑、身份与布局；私有工作流拥有参数与素材状态。保存时验证节点、插槽和连线。
  保存插槽必须带稳定端口 ID；不能用旧插槽索引解释新端口顺序。损坏卡片隐藏的连线
  在无关保存时保留；删除卡片或明确重接该输入时才移除对应旧绑定。
  图 Undo/标签草稿不回滚已经提交的参数/设置/素材；图恢复后轻量重读值和 revision，
  不重建卡片或计算图，不覆盖状态请求期间产生的新参数草稿。
- 文字素材桩提供独立的聚焦撤销：Ctrl/Cmd+Z 与 Ctrl/Cmd+Shift+Z 只处理当前文本框。
  手工输入/删除/粘贴可回退，生成替换独立成步，中文组合输入不被快捷键抢占。
  撤销/重做沿用素材保存队列和执行屏障；旧保存回包不覆盖新草稿，不新增后端撤销接口。
  每个控件拥有有界字符串历史，不序列化历史，不回滚模型参数或执行任务；空栈也不落入图撤销。
- 保存使用 revision，冲突报错；不覆盖其它标签页的新结果。删除节点不隐式删除素材文件。
  卡片编辑 revision 必须来自实际返回内容的同一次读取，不能先读内容再另读文件计算版本。
  派生执行图损坏时允许打开原生工作流修复，不使用损坏快照裁剪节点。
- 素材提交写入私有卡片，不附带布局保存；保存队列绑定所属项目，不能借用当前标签页。
- 播放器按需建立，默认不自动播放；切标签、离屏、页面隐藏和移除节点时释放。
- 裁剪保存到私有卡片；读取时同时解析当前素材与范围。模型缓存沿用 ComfyUI，不能全局清理模型。
  等待缺失素材期间只保留当前逻辑任务已完成分支的必要输出，避免重复采样/Chat；
  被消费的祖先及时释放，阻塞结果不复用，终态释放全部续执行状态，不跨任务缓存。
  输入连线按桩身份，在读取节点实际执行时解析当前选中素材，不固定提交时的文件。
  同一任务首次成功读取后固定该输入版本，依赖重试不能混入后来选择的素材。
  原生 reader 的 resumed 状态必须改变缓存签名，使此前被阻塞的模型配置节点重新执行；
  不清空正常模型缓存，不以历史文件时间决定素材选择。
- 缺失/空文本的上游边界通过同一局部任务 API 递归生成，成功发布后再编译下游。
  由原生 lazy 求值实际读取时请求依赖，未选分支不生成、不等待。
  同一段冻结参数、像素上限与随机值；依赖就绪后恢复读取，不再次随机化。
  已有素材不重新计算；若来源正在执行则等待其新发布。循环、无生成来源或空生成结果必须停止。
- 卡片局部提交不调用整图控件回调；在首次有效入队前推进 fixed/increment/decrement/randomize。
  真实运行时接线不推进，Inputs 表单展开后的标量可以推进；一份表单的多个消费者共享取值。
  新保存文件按 linkedWidgets 捕获明确控制关系，旧 named/标准 positional 快照仍可读取。
  原生数值范围/步长及子图命名空间保留，普通 COMBO 控制支持候选项及 increment-wrap。
  控制模式与轻量游标属于私有 workflow.json；表单及动态分支回写实际值，手工编辑重置游标。
  验证失败不提交游标；依赖重试只推进一次，不覆盖验证期间的新手工编辑。
  自动数值推进不是结构修改，不制造卡片编辑文件冲突；显式保存工作流重建游标。
  模板不改写，原生执行历史保留实际输入和 extra_data.turing_value_controls。
  Canvas 使用明确的执行前语义，不读取整图队列的 Comfy.WidgetControlMode 设置。
- 卡片右上角蓝色 ▶ 和画布右键“执行选中卡片”由服务端持有整个批次并规划素材拓扑顺序。
  有计算输入的桩全部重新执行，纯加载桩读取已有选择；未导出桩同样参与。
  每一步发布后再继续，同一卡片的重复点击共享正在运行的批次，不预建整批任务或缓存中间张量。
  循环在任何提交前报错；失败/中断停止剩余步骤，已执行却输出为空的上游不重复生成。
  手工选择导致发布未选中时停止剩余步骤，新结果仅进入历史。
  后端持久化批次状态，浏览器断开后继续运行；重连恢复观察，服务器重启显式标记中断。
  所有实际计算通过唯一原生 worker；前端不直接拼装或提交分段 /prompt。
  除明确的素材读写/Canvas Chat 适配外，普通 class_type 不改名；先应用 Stage Barrier / shared-loader 变换。
  仅任务拥有的输出、对象与外部 cache-provider 读写被隔离，模型准备仍遵从原生缓存。
- 媒体预览右键复用原生 ContextMenu，分别下载原文件或当前裁剪/像素上限后的输出；文本框保留正常编辑菜单。
- 裁剪双手柄与播放位置共用一条时间轴，精确数值临时编辑，不占用卡片表单行。
  管理动作进入右键；生成按钮文字及标题保持稳定，状态用按钮/预览边缘颜色及悬浮提示表达。
  未变化的状态、参数和控制模式不重复回写控件，不重建文本框或标题。
- 桩的 canvas_show_generate / canvas_generate_label 只控制卡片按钮，默认显示“生成”。
  隐藏按钮不影响批次规划，预览右键始终提供标准“生成”。文本预览外边距提供素材菜单，
  内层 textarea 保留原生编辑菜单及聚焦撤销；两种渲染器挂载同一个轻量 DOM 控件。
  展示选项保存在节点 properties，投影读取，不进入执行输入或模型缓存。
- 卡片保留已保存尺寸及 Inputs 的交错顺序。先预留每项最小高度，再按图片/视频、文本、音频、表单顺序分配空间；
  同级预览公平扩展到实际素材比例需要的高度，空预览和音频不占用多余高度。画面 contain，不裁掉原件。
  card_layout.js 只调整卡片实例的控件高度；经典布局和 Nodes 2.0 网格共享分配逻辑，不修改全局原型或从 DOM 反推 node.setSize。
  比例来自既有缩略图/播放元信息；缩放不请求媒体。观察器、动画帧和播放器随卡片移除释放。
- Chat URL 选择凭据所有者：空 URL 使用项目 URL/Key，非空 URL 仅使用卡片 Key，Model 独立回退。
  仅 Canvas 编译替换为私有 Chat 适配器，通过项目引用在执行时读取全局设置，普通 Chat 不变。
  项目回包只含 api_key_set，日志脱敏并拒绝跨域重定向；不把全局 Key 放入队列、模板或素材元信息。
- 实例和模板删除都确认；实例保留媒体/工作流，模板移入 .trash。原生删除不能绕过确认。
  仅画布的 deleteSelected 接入同一删除流程，覆盖原生键盘/菜单/工具栏；不拦截键盘事件。
  多选一次确认并原子保存，取消或保存失败保留全部卡片；项目根节点不删除。
- 只封装缺失的项目语义，不引入通用组件框架，不导入前端带 hash 的内部打包文件。
- 新增卡片只插入新原生节点，不重载项目、不重建已有控件和连线；会话裁剪状态保持不变。
- 项目读取在单次请求内复用 canvas.json 快照；布局保存只检查已连线卡片的接口，
  不展开执行图、不读取无连线卡片。编译执行时仍重新校验实际卡片内容。
- 展示只生成卡片描述，不展开计算图；执行只展开目标卡片。跨卡片读取已发布素材，
  不为了执行一张卡片加载所有卡片的工作流。
- 素材发布先持久化任务意图，再更新私有 workflow.json。中断后重试或重新打开项目可恢复；
  不覆盖之后发生的手工选择，也不重复增加选择版本。
- 缩略图服务限制并发并合并重复请求；请求取消不取消其它请求正在等待的解码。
  成功完成的保存队列释放；失败仅保留对应项的错误，修正后释放，不保留任务图或媒体张量。
- 原生界面只保留一套选择、连线保存和任务提交 API；不保留旧独立网页的重复入口。
- 同目录与类型的历史 combo 共享已加载的文件列表；内容变化后显式刷新。
  列表分页 120 条，保留页外当前选择，查询按文件名过滤；加载中刷新合并，旧查询不覆盖新查询。
  重复/过期发布通知不重置播放器、不覆盖新选择；批次结束不隐式保存界面布局。
  不缓存媒体解码张量或另存模型权重，不改变原生历史下拉的使用方式。
- 高清预览按缩略图采样密度切换（进入 1.15×、退出 0.85×），不是节点逻辑宽度或当前原图尺寸。
  画布缩放复用 ds.onChanged 实例回调；ResizeObserver/IntersectionObserver 只服务可见预览，稳定 200 ms 后批量检查。
  一个下载、一个最新悬停候选、八个自动候选，悬停可抢占自动下载。LRU 淘汰同时降级使用者，不留下无限的 DOM 原图引用。
  大原件只有一个临时槽；自动请求估算超过 64 MiB 时不展示，手动悬停仍可用。刷新/离屏/移除取消旧请求并释放引用。
  视频高清只生成按素材版本、时刻、质量分开的 PNG 帧缓存，和播放/素材输出无关；不得因放大自动建立播放器。

## 前端升级边界

优先使用 app.registerExtension、原生节点生命周期、工作流公共动作与控件。
不依赖带 hash 的打包文件、私有 store 导入或全局剪贴板重写。
当前无法完全消除的适配只有各自明确的职责：托管文件实例的保存/加载及 Save 命令、
画布整图 Run 阻断、项目右键菜单、动态槽位/原生子图版本修复、端点 DOM 事件桥和媒体渲染定义。
普通工作流均委托原生路径；升级后的差异应限制在对应前端适配文件，不扩散到后端协议。
Nodes 2.0 的 DOM 选择器集中在 endpoint_dom.js；原生旧草稿字段仅在一次性迁移桥中出现。
升级时先跑两种渲染器的保存恢复、原生复制和动态槽位回归，修复或删除对应适配，
不通过再增加一套保存、图编辑或模型缓存实现来兼容。
