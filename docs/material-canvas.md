# 画布

画布使用 ComfyUI 原生工作流标签页、LiteGraph 节点和控件，不需要 Nodes 2.0，
不再提供独立网页。工作流定义计算，素材桩定义持久化边界。

## 操作

1. Turing Utils → 新建画布，使用三列目录弹窗浏览服务器 output 内的文件夹。
   必须选择已存在的空文件夹，也可以新建文件夹；隐藏文件也算内容。
   不覆盖非空文件夹。取消不创建项目。
2. 打开画布选择项目中的 canvas.json；编辑卡片选择卡片库中的 JSON 文件。
   不会自动创建缺失文件。
3. 画布在原生标签页打开，包含一个锁定的 Canvas Project 节点。
   标签标题包含项目目录名。开启 ComfyUI 的工作流持久化后，刷新页面恢复打开的
   画布、标签顺序、当前标签及未保存草稿；已关闭的标签不会重新打开。
   右键添加节点，选择基础素材或卡片库模板。实例为独立副本。
   原生复制/粘贴卡片同样创建新实例：工作流文件、参数及素材选择互相独立，
   已有媒体文件只读共用，不重复拷贝大视频。复制多张卡片保留副本之间的连线。
   复制完成前暂不开放副本控件；失败只移除失败副本，不影响原卡片与已成功的副本。
4. 使用普通控件编辑参数和文本，导入素材或从下拉框选择历史。
   导入的媒体拷贝到项目内；文本内联保存，没有文本文件。
5. 参数、素材选择和裁剪自动写入所属私有卡片文件，不顺带保存其它布局修改。单独修改连线、位置、大小后，
   使用原生 Save / Ctrl+S 或 Turing Utils → 保存画布。
   项目图保存到 canvas.json，不另存一份普通工作流；暂不支持复制整个画布项目的另存为。
6. 素材区域的“生成”只执行上游两个素材边界之间的计算。
   卡片右上角蓝色 ▶ 按内部依赖顺序生成全部桩，隐藏局部按钮的桩也参与。
   画布和项目内卡片编辑页的全局 Run 都报错，不提交整张图。
   全局卡片模板仍可独立执行测试。
7. 画布右键“执行选中卡片”批量执行选中的卡片，跨卡片依赖也按拓扑顺序排列。
   项目节点右键“撤销未保存修改”重新读入已保存文件，丢弃尚未提交的界面修改；
   已保存素材和服务端正在执行的任务不受影响。
   原生 Undo 管理尚未保存的图布局；已写入文件的参数、设置和素材选择不会被旧图快照回滚。
   切换标签或 Undo 恢复后重新对齐已保存值，避免界面显示值与推理使用值不一致。
   文字素材桩例外：聚焦卡片上的文本框后，Ctrl/Cmd+Z 撤销文字，Ctrl/Cmd+Shift+Z 重做，
   回退后的文字同样自动写入私有卡片。连续输入合并，生成替换独立成步；不撤销内部参数或任务。
   撤销历史只在当前控件打开期间保留，重新打开不恢复历史；每桩最多 64 步并限制历史字符串容量。

## 制作卡片

“新建卡片”在新标签页打开 Inputs、Outputs 和四类素材桩的基础工作流。
初始端点为空，六个节点之间没有预设连线；各素材桩的 position 位于第一个素材插槽。
删除不用的桩，加入普通节点，再按需要连线。保存卡片时，每个桩必须连接输入端点的位置口；
输出端点连接可选，仅决定哪些素材可供下游卡片连线。未导出的桩仍保留预览、选择与局部执行。
卡片输出端点只允许导出桩；是否来自桩在保存卡片时校验，普通工作流编辑时不限制来源。
素材端点的数据类型限制始终生效。

端点两侧的“＋”自动创建配对插槽，素材连线接受 IMAGE、VIDEO、AUDIO、STRING。
Inputs 还接受 INT、FLOAT、BOOLEAN、STRING 和 COMBO 表单参数：将“＋”连接到
普通节点的参数输入，自动继承其默认值、数字控件设置或下拉选项。工作流中的 Inputs
也显示对应控件，可独立测试。表单参数只有右侧输出口，没有对应的左侧输入口；
左侧只接收素材。卡片上参数是表单，不是跨卡片连线口。
参数值按稳定端口 ID 保存到私有 workflow.json 的端点默认值，同时更新原生控件与派生执行图。
素材选择、裁剪、运行游标归属该文件的 turing_card.state；canvas.json 不保存它们。
编辑实例工作流会恢复当前值，不修改模板。编辑器保存按打开时的基线合并较新的参数和素材，
只有同一字段发生不同修改或结构冲突才报错。
MODEL、CLIP、VAE、LATENT、CONDITIONING、MASK 和任意未知自定义类型不允许输入端点导出。
下拉只接受可序列化的标量选项，不持久化函数、模型对象或张量。
原生 DynamicCombo 可整组导出，包含嵌套分支，沿用原生下拉和表单控件。
组内所有分支必须都是可填写参数；包含模型、张量或强制连线输入的组不能导出。
切换分支保留各自填写值，执行只展开选中分支。整组连接后不能再给组内字段单独接线；
不同定义的参数组不能互接。组在 Inputs 上只有输出口，不能用运行时连线决定分支。
参数修改不会自动生成或覆盖已发布素材。工作流独立执行也使用同一分支展开规则。
位置标记仅绑定素材桩，不传递数据。在端口名称上右键，直接选择重命名、上移、下移或删除；
双击名称也可改名，名称不能留空。经典节点与 Nodes 2.0 使用同一组操作，不提供拖拽排序。
端口 ID 不随顺序变化，连线和撤销由原生图管理。
表单参数名称的右键菜单可勾选“隐藏参数”；条目显示“· 隐藏”，只影响展示，不改变端口、值或执行。
卡片右键“隐藏参数…”打开按来源节点分组的设置窗口，支持搜索、DynamicCombo 分支和数值推进模式。
取消不写入，应用统一保存到私有工作流；窗口打开期间同一参数被修改时提示重新打开。
素材口、位置标记和文本素材桩不能隐藏。旧工作流没有该标记时仍显示原有参数。

Text 桩只有 text 字符串输入和文本框，连接后文本框保留，结果随工作流/项目保存。
媒体桩采用官方 combo 和上传控件，按钮为 choose file to upload。
媒体桩的普通开关“在卡片显示上传入口”控制提取到卡片后的预览右键上传和文件拖入，
默认开启；关闭后仍可选择历史素材和执行生成，不影响普通工作流的上传控件。
该选项保存在工作流节点 properties 中，不参与推理参数或模型缓存。
每个桩另有“在卡片显示生成按钮”和“生成按钮文字”：默认显示，文字留空为“生成”。
隐藏只移除按钮行；媒体预览右键仍可生成，文本框外侧边缘提供生成、复制和下载菜单，
文本框内仍使用普通编辑菜单。这些展示选项随模板及私有卡片工作流保存。

新卡片首次 Save / Ctrl+S 选择文件名，之后直接写入该模板文件。
菜单“保存卡片”明确创建新模板，始终选择新文件名，重名拒绝覆盖；不等同于 Ctrl+S。
普通工作流使用“保存卡片”进入卡片库；编辑卡片工作流打开实例的独立标签页。
实例的 Save / Ctrl+S 先写入 cards/<实例 ID>/workflow.json，再保存所属画布布局，不改变模板或其它实例；
关闭标签时选择保存也写入同一文件，冲突或取消时不清除未保存状态。
卡片另存为创建独立模板及标签页，不重新绑定当前项目副本。
实例导出保留内部结构、隐藏标记及当前参数，清除项目私有媒体文件绑定和状态。
直接配置的明文 Chat Key 不导出，环境变量引用可保留；不重建已移除的外部测试支路。
Turing Utils → 复制卡片选择已有模板，在新标签页打开未保存的独立副本。
修改后 Save / Ctrl+S 指定新文件名；不会覆盖原模板，取消选择不创建副本。
普通工作流的原生保存行为不变。返回画布标签页时使用更新后的接口。
旧版本 canvas/ 标签升级时，只迁移明确打开/选中的标签及其原生草稿，
不扫描或重新打开已关闭的历史草稿。旧版已丢失的混合标签顺序无法反推，
仅剩当前画布引用时恢复到普通标签之后。原生文件与画布逻辑路径冲突时保留原生文件并报错。
卡片文件保存完整的原生编辑器快照，包括动态槽位、空槽和子图；执行参数图单独派生。
保存与打开时按原生 Autogrow 分组整理槽位并同步连线索引，不依赖 Recreate 修正布局。
官方、第三方及本插件动态节点在原生克隆/子图配置后按名称保留槽位与连线，
覆盖 Autogrow、DynamicCombo 和 JS 增加的槽位。已有子图再包一层不会丢失内部连线。
打开/保存检查连线一致性，发现端口或类型错配会报错；已保存的同类型错接需手工确认，
不能自动猜回原始来源。
项目副本自动移除输入端点前、输出端点后的测试节点和连线，保留内部计算及原生子图；
全局模板保留这些测试支路。项目编辑页的素材历史、上传及局部执行都绑定所属项目。
选择历史或修改桩文本立即更新画布的素材选择；结构和参数修改仍需 Save / Ctrl+S。
保存和局部执行等待已发起的素材编辑、上传及选择完成；写入失败会阻止执行，重新选择成功后可重试。
卡片上的素材与参数按输入端点中的交错顺序展示。
新增素材桩须先保存后才能写入项目。选择素材不会触发下游执行。
外部编辑器改写 workflow.json 后，旧执行快照失效；先在编辑页重新保存才能执行。
此时不使用旧快照清理源节点，以免删除外部新增的内容。
媒体列表只在相关导入/生成后刷新，不显示或启用“Auto-refresh after generation”。
原生子图仍可作为内部计算节点使用；Canvas 本身不依赖顶层子图。

## 媒体与缓存

Nodes 2.0 下，素材桩和卡片的历史下拉使用原生预览选择面板；经典界面保持标准下拉。
卡片及项目编辑页只浏览当前项目历史。图片/视频候选项加载静态缩略图，
不会在展开历史时开始播放视频或音频；项目上传使用预览右键 choose file to upload 或文件拖入。
历史每页最多加载 120 个文件，可在同一下拉中加载更多或按文件名查找。
当前选择即使不在第一页也会保留，不将缩略图地址当成素材文件。

视频桩复用官方 Create Video，输出 VIDEO；拆帧/音频用官方视频组件节点。
图片默认缩略图，悬停原位显示原图，移出恢复；拖入文件时禁止原图请求。
原图请求全局只有一个正在下载和一个最新候选，旧请求取消，缓存最多四项和 32 MiB 的估算预算。
视频/音频只有点击预览才建立播放器，播放位置和裁剪起止点共享一条时间轴。
区间高亮，播放限制在选中区间；点击起止时间可精确输入。拖动时不逐帧持久化，释放后保存。
预览展示该桩当前选中的持久化素材，也是下游读取的版本；修改参数不会自动覆盖它。
不自动播放或循环。切换标签、离屏或隐藏页面时释放播放器。
预览右键提供“下载原始素材”“下载当前输出”和“素材信息”。后者说明原件与当前下游输入尺寸。
当前输出按裁剪及像素上限临时导出，导出同时仅允许一份，传输完毕删除临时文件，不加入素材历史。
原件下载不改变大小和格式，不下载缩略图。
图片素材重读保留 RGB/RGBA，包括调色板透明度；JPEG 缩略图仅对白底合成，不改变素材 alpha。
修改素材选择也会停止旧播放器并更新预览，不继续播放已经取消选择的版本。
起点/终点保存到私有卡片工作流，刷新后保留；0 终点代表末尾。
只改变播放和下游读取视图，不修改原件；裁剪变化不阻止执行中的新素材发布。

服务端任务仍通过 ComfyUI 原生队列及其唯一推理 worker 执行，没有第二套推理引擎。
浏览器只提交任务和观察状态，刷新或断开浏览器不停止已提交任务；重新打开恢复当前选择与任务状态。
服务端重启后，未完成任务显示中断，不自动重跑；已成功发布的素材保留。
模型及 LoRA 复用原有缓存；
只清理本次普通中间结果，不全局清空模型。执行期间手工改变素材不会被旧任务覆盖。
打开项目不展开卡片内部计算图，执行才展开目标卡片；已有素材的上游卡片只读取已发布素材。
局部执行实际读取到未发布的上游桩或空文本时，才递归执行该桩，成功发布后继续原任务。
原生 lazy 分支中没有被选中的缺失素材不会触发生成。
等待缺失素材后继续执行，不重新调用已经完成的计算分支；只保留当前任务需要的分支输出，
任务结束即释放，不增加跨任务中间结果或模型副本缓存。
在 A 正在生成时请求依赖 A 的 B，B 等待 A 发布新素材；不会静默使用 A 的旧版本。
已有选中素材不重新生成；循环依赖、没有生成来源或生成后仍为空会停止并报错。
卡片连线引用素材桩身份，不绑定点击执行时的文件或文本。真正执行到读取节点时，
才使用该桩当时选中的素材；排队期间切换历史或上游发布结果都会被读取到。
这里不是选择目录里“最新生成的文件”。首次成功读取后，在同一逻辑任务的依赖重试中
保持该版本；再次执行才重新读取当前绑定。普通工作流素材节点的显式文件选择不变。
内部控件或卡片的独立标量表单支持 fixed/increment/decrement/randomize。
卡片使用执行前推进语义；同一表单接多个消费者只取值一次。真正的运行时接线不推进，
Inputs 展开的可填 seed 可以推进。等待上游重试不再次改变；读取已发布素材不触发上游控制。
控制模式、游标和暴露表单的实际值保存到私有 workflow.json；重新打开后继续，手工修改会重置游标。
界面显示实际入队值；普通 COMBO 控制还支持 increment-wrap。模板参数不改写。
自动推进不导致编辑页文件冲突；实际值记录在执行历史 prompt 和 extra_data.turing_value_controls。
DynamicCombo 分支的原生控制模式与取值一起保存，运行值回写对应分支，未选分支不推进。
生成按钮文字和卡片标题不随轮询改变。等待用黄色虚线、生成中用蓝色、已完成用绿色标记；
隐藏按钮时预览边缘仍显示状态，错误及批次进度放在悬浮提示。
取消/中断使用原生队列；原生任务被移除或中断后不继续剩余桩，已保存素材保留。
卡片右上角 ▶ 按内部素材依赖的拓扑顺序，逐个重新执行有计算输入的桩，
包括未导出的桩；纯加载桩复用当前选择。每一步发布成功后才执行下一步。
批次内循环依赖在开始前报错；递归或并发依赖循环也会停止。
失败或中断停止后续执行，已成功的结果保留。连续重复点击不重复排队。
执行中手工选择其它历史素材会保留手工选择，新结果只加入历史，剩余批次停止。
素材发布若在写入与更新画布之间中断，重新打开项目会继续完成提交，且保留更新的手工选择。
Project 节点提供项目名称、素材像素上限（默认 4.0 MP）、统计和保存状态。
右键“隐藏参数…”的 Chat 分组配置项目默认 URL、Model 与 Key，Key 遮蔽显示，同源服务留空保持原 Key，单独开启清除。
更换全局服务的协议、主机或端口时需重新填写 Key，不能自动转发旧凭据。
卡片 Chat URL 为空时使用全局 URL/Key；URL 非空时只使用卡片 Key（为空也不继承）。
Model 始终卡片非空优先，否则继承全局。即使 URL 相同，明确填写也视为卡片配置。
设置在请求执行前解析，不写回卡片；全局 Key 不出现在普通回包、队列输入或模板。
优先使用 $NAME 环境变量引用；项目私有文件存储不是加密。跨域重定向明确拒绝。
像素上限只在执行时读取素材，按需缩小输入；不改写已发布的原始文件。
低于上限的素材不会自动放大；参考图缩放和采样尺寸仍由卡片工作流决定。
Qwen Image 2.1 编辑应使用官方条件节点的 latent 输出与第一张参考图对齐；
其 resolution=0 保留参考图尺寸（按 32 对齐），1024 表示约 1024×1024 总像素，
不是最长边 1024。提高该参数不能恢复原素材已经丢失的细节。
目录弹窗允许删除空目录树，包含文件或符号链接时拒绝删除。

## 文件

```text
user/<用户>/canvas_cards/<名称>.json
output/materials/image|video|audio/...  # 素材桩作为普通工作流执行时的结果
output/<项目>/
  canvas.json                      # 格式 4：身份、文件引用、布局、连线、视口
  cards/<实例 ID>/workflow.json    # 原生工作流、参数、素材选择、裁剪、运行游标
  cards/<Root ID>/workflow.json    # 全局设置
  workspace.sqlite3               # 媒体索引、任务记录
  .canvas-commit.json              # 仅多文件提交未完成时存在；重开恢复，不手动删除
```
