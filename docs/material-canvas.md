# 画布

画布使用 ComfyUI 原生工作流标签页、LiteGraph 节点和控件，不需要 Nodes 2.0，
不再提供独立网页。工作流定义计算，素材桩定义持久化边界。

## 操作

1. Turing Utils → 新建画布，使用三列目录弹窗浏览服务器 output 内的文件夹。
   必须选择已存在的空文件夹，也可以新建文件夹；隐藏文件也算内容。
   不覆盖非空文件夹。取消不创建项目。
2. 打开画布选择项目中的 canvas.json；编辑卡片选择卡片库中的 JSON 文件。
   不会自动创建缺失文件。
3. 画布在原生标签页打开，包含一个锁定的 Canvas Project 节点。
   右键添加节点，选择基础素材或卡片库模板。实例为独立副本。
4. 使用普通控件编辑参数和文本，导入素材或从下拉框选择历史。
   导入的媒体拷贝到项目内；文本内联保存，没有文本文件。
5. 素材写入、导入和历史选择成功后自动保存项目。单独修改连线、位置、大小后，
   使用原生 Save / Ctrl+S 或 Turing Utils → 保存画布，也可点击全局节点的“保存项目”。
   项目图保存到 canvas.json，不另存一份普通工作流；暂不支持复制整个画布项目的另存为。
6. 素材区域的“执行到这里”只执行上游两个素材边界之间的计算。
   画布和项目内卡片编辑页的全局 Run 都报错，不提交整张图。
   全局卡片模板仍可独立执行测试。

## 制作卡片

“新建卡片”在新标签页打开 Inputs、Outputs 和四类素材桩的基础工作流。
初始端点为空，六个节点之间没有预设连线；各素材桩的 position 位于第一个素材插槽。
删除不用的桩，加入普通节点，再按需要连线。保存卡片时，每个桩必须同时连接输入端点的位置口和输出端点的内容口。
卡片输出端点只允许导出桩；是否来自桩在保存卡片时校验，普通工作流编辑时不限制来源。
素材端点的数据类型限制始终生效。

端点两侧的“＋”自动创建配对插槽，素材连线接受 IMAGE、VIDEO、AUDIO、STRING。
Inputs 还接受 INT、FLOAT、BOOLEAN、STRING 和 COMBO 表单参数：将“＋”连接到
普通节点的参数输入，自动继承其默认值、数字控件设置或下拉选项。工作流中的 Inputs
也显示对应控件，可独立测试。表单参数只有右侧输出口，没有对应的左侧输入口；
左侧只接收素材。卡片上参数是表单，不是跨卡片连线口。
参数值按稳定端口 ID 内联保存在 canvas.json 的卡片实例 parameters 中；
不修改模板或实例 workflow.json。编辑实例工作流会恢复当前参数值。
MODEL、CLIP、VAE、LATENT、CONDITIONING、MASK 和任意未知自定义类型不允许输入端点导出。
下拉只接受可序列化的标量选项，不持久化函数、模型对象或张量。
原生 DynamicCombo 可整组导出，包含嵌套分支，沿用原生下拉和表单控件。
组内所有分支必须都是可填写参数；包含模型、张量或强制连线输入的组不能导出。
切换分支保留各自填写值，执行只展开选中分支。整组连接后不能再给组内字段单独接线；
不同定义的参数组不能互接。组在 Inputs 上只有输出口，不能用运行时连线决定分支。
参数修改不会自动生成或覆盖已发布素材。工作流独立执行也使用同一分支展开规则。
位置标记仅绑定素材桩，不传递数据。在端口名称上右键，直接选择重命名、上移、下移或删除；
双击名称也可改名，名称不能留空。经典节点与 Nodes 2.0 使用同一组操作，不提供拖拽排序。
端口 ID 不随顺序变化，连线和撤销由原生图管理。

Text 桩只有 text 字符串输入和文本框，连接后文本框保留，结果随工作流/项目保存。
媒体桩采用官方 combo 和上传控件，按钮为 choose file to upload。
媒体桩的普通开关“在卡片显示上传入口”控制提取到卡片后的上传按钮和文件拖入，
默认开启；关闭后仍可选择历史素材和执行生成，不影响普通工作流的上传控件。
该选项保存在工作流节点 properties 中，不参与推理参数或模型缓存。

新卡片首次 Save / Ctrl+S 选择文件名，之后直接写入该模板文件。
普通工作流使用“保存卡片”进入卡片库；编辑卡片工作流打开实例的独立标签页。
实例的 Save / Ctrl+S 写入 cards/<实例 ID>/workflow.json，不改变模板或其它实例；
关闭标签时选择保存也写入同一文件，冲突或取消时不清除未保存状态。
卡片另存为创建独立模板及标签页，不重新绑定当前项目副本。
Turing Utils → 复制卡片选择已有模板，在新标签页打开未保存的独立副本。
修改后 Save / Ctrl+S 指定新文件名；不会覆盖原模板，取消选择不创建副本。
普通工作流的原生保存行为不变。返回画布标签页时使用更新后的接口。
项目副本自动移除输入端点前、输出端点后的测试节点和连线，保留内部计算及原生子图；
全局模板保留这些测试支路。项目编辑页的素材历史、上传及局部执行都绑定所属项目。
选择历史或修改桩文本立即更新画布的素材选择；结构和参数修改仍需 Save / Ctrl+S。
新增素材桩须先保存后才能写入项目。选择素材不会触发下游执行。
外部编辑器改写 workflow.json 后，旧执行快照失效；先在编辑页重新保存才能执行。
此时不使用旧快照清理源节点，以免删除外部新增的内容。
媒体列表只在相关导入/生成后刷新，不显示或启用“Auto-refresh after generation”。
原生子图仍可作为内部计算节点使用；Canvas 本身不依赖顶层子图。

## 媒体与缓存

视频桩复用官方 Create Video，输出 VIDEO；拆帧/音频用官方视频组件节点。
图片和视频缩略图按需加载。视频/音频只有点击预览才建立播放器，使用浏览器默认控件；
预览展示该桩当前选中的持久化素材，也是下游读取的版本；修改参数不会自动覆盖它。
不自动播放或循环。切换标签、离屏或隐藏页面时释放播放器。
修改素材选择也会停止旧播放器并更新预览，不继续播放已经取消选择的版本。
起点/终点是会话控件，不写入工作流或项目，刷新后重置；0 终点代表末尾。

执行继续使用 ComfyUI /prompt 和 WebSocket。模型及 LoRA 复用原有缓存；
只清理本次普通中间结果，不全局清空模型。执行期间手工改变素材不会被旧任务覆盖。
打开项目不展开卡片内部计算图，执行才展开目标卡片；上游其它卡片只读取已发布素材。
素材发布若在写入与更新画布之间中断，重新打开项目会继续完成提交，且保留更新的手工选择。
Project 节点提供项目名称、素材像素上限（默认 4.0 MP）、统计和保存状态。
像素上限只在执行时读取素材，按需缩小输入；不改写已发布的原始文件。
目录弹窗允许删除空目录树，包含文件或符号链接时拒绝删除。

## 文件

```text
user/<用户>/canvas_cards/<名称>.json
output/materials/image|video|audio/...  # 素材桩作为普通工作流执行时的结果
output/<项目>/
  canvas.json                      # 格式 3：实例及表单参数、布局、连线、文本、素材选择
  cards/<实例 ID>/workflow.json    # 普通 ComfyUI 工作流
  workspace.sqlite3               # 媒体索引、任务记录
  materials/image|video|audio/...
```

项目目录目前限于本实例 output，不访问另一实例或浏览器电脑的路径。
旧独立网页的格式 2 项目明确拒绝打开，不自动迁移或删除其素材。
删除画布节点仅移除项目引用，不删除磁盘素材和工作流副本。
已有历史媒体只读，不因再次执行加载而产生新版本；input 中导入的文件入库一次。

节点样式与交互由原生编辑器负责；性能上限随 ComfyUI 前端版本和可见预览数量变化，
不承诺无限节点。维护约束见 [交互契约](canvas-interaction-contract.md)。
